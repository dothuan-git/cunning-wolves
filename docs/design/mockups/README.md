# Mockups

Approved screen images. They are the source of truth for UI: if code and a mockup differ, ask before changing either.

## Naming

`<screen>.png` for the Vietnamese version, `<screen>.en.png` for English. Size 390×844 at 1× or 3× scale.

| Screen           | File name          |
| ---------------- | ------------------ |
| Home / room list | `home.png`         |
| Name entry       | `name-entry.png`   |
| Game summary     | `summary.png`      |
| Master lobby     | `master-lobby.png` |
| Setup            | `setup.png`        |
| Narrator page    | `narrator.png`     |
| Player lobby     | `player-lobby.png` |
| Rules review     | `rules-review.png` |
| My card          | `my-card.png`      |

Extra states get a suffix, for example `my-card.flipped.png` and `narrator.dead-player.png`.
