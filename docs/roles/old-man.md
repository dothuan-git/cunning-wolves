# Old Man / Ông lão

- **id:** `old-man`
- **Team:** village
- **Wakes at night:** no
- **Card art:** missing

## Rule (vi)

Bạn chết vào đêm X, với X là số sói cộng một. Mỗi con sói chết làm bạn chết sớm hơn một đêm.

## Rule (en)

You die on Night X, where X is the number of werewolves plus one. Each werewolf that dies makes it one night sooner.

## Narrator notes

From Ultimate Werewolf (Bézier Games) role list. Count the werewolves at the start and tell no one. Some groups bring the death night forward when a werewolf dies earlier; agree on this before the game. The app shows the card and rule only; it does not run this role’s power.
