# Angel / Thiên thần

- **id:** `angel`
- **Team:** solo
- **Wakes at night:** no
- **Marks:** none
- **Card art:** missing

## Rule (vi)

Ván bắt đầu bằng cuộc bỏ phiếu của làng trước đêm 1. Nếu bạn bị loại ở đó, hoặc chết trong đêm 1, bạn thắng và ván kết thúc. Nếu không, bạn thành dân làng thường.

## Rule (en)

The game starts with a village vote before Night 1. If you are voted out then, or killed on Night 1, you win and the game ends. Otherwise you become a plain villager.

## Narrator notes

Before Night 1, the village debates and votes someone out: hold that vote, then start the game and mark the death in Night 1. If the Angel was voted out, or dies on Night 1, they win and the game ends: press Finish. Otherwise the Angel plays as a plain villager.
