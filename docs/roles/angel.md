# Angel / Thiên thần

- **id:** `angel`
- **Team:** solo
- **Balance:** +1 (estimate, compared with the Tanner)
- **Wakes at night:** no
- **Changes roles:** yes: the narrator can give a player another role while it is dealt
- **Card art:** `apps/web/src/assets/cards/angel.webp`

## Rule (vi)

Ván bắt đầu bằng một lần bỏ phiếu treo cổ trước đêm 1. Nếu bạn bị treo cổ ở đó, hoặc chết trong đêm 1, bạn thắng và ván kết thúc. Nếu không, bạn thành dân làng thường.

## Rule (en)

The game starts with a hanging vote before Night 1. If you are hanged then, or killed on Night 1, you win and the game ends. Otherwise you become a plain villager.

## Narrator notes

Before Night 1, run the day vote (hanging vote, gallows, life-or-death vote), then start the game and mark the death in Night 1. If the Angel was hanged, or dies on Night 1, they win and the game ends: press Finish. Otherwise the Angel plays as a plain villager.
